# Errata

Corrections to *Maths for LLMs*, in print order. Reported by readers or found in
review; each is dated and each says which printing it was fixed in.

The short URL for this page is printed in the front matter of every copy.

## How to report

Open an issue with the label `erratum`, giving the page, the equation or box
number, and what you think is wrong. You will be credited by name in the second
edition unless you ask not to be. A correction that changes a derivation rather
than a typo is worth more than a bug report and will be treated as such.

## First edition, first printing

*No errata yet. This file exists from day one, which is the point: a book with a
public errata page from publication is making a different claim than one that
adds it after the first complaint.*
